da Universidade de Brasília.

## Como rodar o projeto localmente

1. Clone este repositório:
   `git clone https://github.com/unb-mds/G2-2026-2.git`
2. Entre na pasta:
   `cd G2-2026-2`
3. Instale o Python (e outras dependências necessárias) e rode a aplicação:
   `python run.py` *(ou o comando que vocês usam)*
